- Delta BFB 97×94×33 datasheet: https://partner-am.deltaww.com/Products/FANUploads/Specification/BFB97x94x33mm.pdf
- Kernel module source: https://github.com/mobius/kunlun_k200 (`884178c135d0e8fa768a1e501dea0f8d3aaa899d`)

- Device compiler (`clang-10`, aarch64) inside the DDK: https://paddle-wheel.bj.bcebos.com/kunlun/xpu_sdk_v2.0.0.61.tar.gz
- Paddle inference demo: https://github.com/PaddlePaddle/Paddle-Inference-Demo
